# Apostila de Algoritmos e Lógica de Programação

Esta apostila foi organizada para apoiar o estudo progressivo de **Algoritmos e Lógica de Programação (ALP)**, com explicações conceituais, exemplos resolvidos, representações visuais, testes de mesa, atividades práticas e exercícios.

## Como utilizar a apostila

1. Estude os conceitos na ordem apresentada.
2. Acompanhe os exemplos resolvidos e procure explicar cada etapa com suas próprias palavras.
3. Faça os testes de mesa antes de executar o código.
4. Resolva os exercícios sem consultar o gabarito inicialmente.
5. Compare as representações em pseudocódigo e em linguagem C quando ambas estiverem disponíveis.
