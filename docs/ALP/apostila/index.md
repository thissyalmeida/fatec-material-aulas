# Apostila de Algoritmos e Lógica de Programação

Bem-vindo(a) à apostila de **Algoritmos e Lógica de Programação (IAL010)**, preparada para apoiar os estudos dos estudantes de Desenvolvimento de Software Multiplataforma (DSM) da FATEC de Registro.

O material foi organizado em uma sequência progressiva: primeiro, vamos aprender a analisar problemas e representar soluções; depois, praticaremos a construção de algoritmos em Portugol/VisualG e avançaremos para a implementação em linguagem C.

## Como estudar

- **Compreenda antes de codificar:** identifique o problema, os dados disponíveis e o resultado esperado.
- **Acompanhe os exemplos resolvidos:** procure explicar cada decisão do algoritmo.
- **Faça testes de mesa:** acompanhe os valores das variáveis passo a passo.
- **Pratique sem consultar o gabarito:** use as respostas comentadas para revisar seu raciocínio.
- **Experimente e depure:** altere entradas, observe resultados e investigue erros.

## Organização da apostila

Os capítulos serão disponibilizados progressivamente e seguirão uma estrutura pedagógica comum: objetivos, explicações detalhadas, recursos visuais, exemplos resolvidos, prática guiada, exercícios, gabarito comentado e síntese.
